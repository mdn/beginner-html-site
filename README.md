# Beginner HTML Site

This is a basic one-page website to help beginners learn the fundamentals of HTML.
You can build up this example by following our [HTML: Creating the content](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content) tutorial.

Also see our [Structuring content with HTML](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content) module for more information on HTML basics.

Please DO NOT file issues on this repo or open pull requests to edit it, even to practice editing on GitHub. We need to keep this content synchronized with the corresponding tutorial. If you find a problem, open an issue about it on [MDN's content repository](https://github.com/mdn/content).
